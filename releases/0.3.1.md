# hyperspace 0.3.1

- À partir de cette version, les notes de version en français figurent sur la page de téléchargement, au-dessus des instructions d’installation.
- À la fermeture de la fenêtre de l’hôte sur le PC, la session dispose désormais de 3 secondes au plus pour se terminer proprement avant l’arrêt de l’hôte.
- Quand un VPN ou un logiciel de sécurité bloque la connexion directe, le message du client ne cite plus aucun produit. Si aucun relais n’est configuré, il indique que le relais de l’hôte (option `--relay`) peut faire passer la session par HTTPS.
- Quand le PC met fin à une session passée par le relais, le client n’affiche plus, juste avant de s’arrêter, une ligne qui laissait croire à une reconnexion.
- La documentation précise ce qui se passe quand le relais ne répond plus pendant une session : le client réessaie seul pendant environ 50 secondes, puis s’arrête avec un message d’erreur.

## À noter

- L’hôte et le client doivent avoir la même version.
